## 6. 作業上の注意（分かったこと）
- **アプリHTMLの改行は CRLF**。Python で書き換えるときは `open(..., newline='')` で読み書きし、挿入する文字列も `\r\n` にする。Edit ツールは問題なし。
- **日本語を含む Python は、ヒアドキュメントではなく、Write ツールで .py ファイル（UTF-8）として保存して実行する**（日本語の検索文字列が一致しないことがある）。コンソールの日本語表示は文字化けする（`PYTHONIOENCODING=utf-8`、結果はファイルに書いて Read で読むと確実）。
