## 6. 作業上の注意（分かったこと）
- **アプリHTMLの改行は CRLF**。Python で書き換えるときは `open(..., newline='')` で読み書きし、挿入する文字列も `\r\n` にする。Edit ツールは問題なし。
- **日本語を含む Python は、ヒアドキュメント（`python - <<EOF`）ではなく、Write ツールで .py ファイル（UTF-8）として保存して実行する**（ヒアドキュメントだと日本語の検索文字列が一致しないことがあった）。コンソールの日本語表示は文字化けする（`PYTHONIOENCODING=utf-8`、結果はファイルに書いて Read で読むと確実）。
- **この PC には node・pandoc・LibreOffice・python-docx がない**。Word は `ai_analysis/make_review_docx.py`（標準ライブラリで .docx を組み立てる）で作る。見た目の確認（PDF化）はできないので、XMLの整合性までを確認している。**出力が大きいデータを画面にそのまま出さない**（ダッシュボードのデータは数MB。構造を要約して見る）。
