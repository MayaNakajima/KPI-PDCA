# data フォルダ（最新の正データJSON）

このフォルダには、KPI・PDCA管理アプリの**最新の正データ（1ファイル）**を置きます。

- アプリのヘッダー「💾 保存(JSON)」を押すと、（バックアップ先フォルダを設定している場合）このフォルダ配下に **`kpi_pdca_data.json`** として上書き保存されます（＝常に最新の正データ）。
- 過去世代のスナップショットは `../backup/rolling/`（更新時＋週次・最新30世代）と `../backup/monthly/`（月次・13世代）に保存されます。
- Power Automate等の自動処理は、この `data/kpi_pdca_data.json` を「最新の正データ」として参照します。

想定フォルダ構成（アプリHTMLを基点）:

```
施策管理表｜PDCA管理/
├─ KPI-PDCA管理アプリ.html
├─ data/
│  └─ kpi_pdca_data.json   ← 最新の正データ（保存(JSON)で上書き）
└─ backup/
   ├─ rolling/             ← 更新時＋週次（最新30世代）
   └─ monthly/             ← 月初営業日（13世代）
```

※ブラウザの制約により、初回のみ「🗄 バックアップ設定」で保存先フォルダ（このHTMLのある `施策管理表｜PDCA管理` フォルダ）を選択してください。以降は `data/` と `backup/` が自動作成・保存されます（Chrome／Edge等）。未設定・非対応ブラウザではダウンロード保存になります。
